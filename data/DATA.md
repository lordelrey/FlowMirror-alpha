# Data policy and inventory (FlowMirror v7)

## Levels

| level | meaning | where it lives |
|---|---|---|
| L0 | raw captures (platform posts, screenshots, crawler dumps, vendor pulls) | never in this repo, never in releases |
| L1 | small derived tables needed by tests and examples | `data/` in this repo |
| L2 | larger derived artifacts | Hugging Face / Zenodo; checksummed in `data/MANIFEST.sha256` |
| L3 | simulation outputs | `runs/` (git-ignored) |

## Inventory

|---|---|---|---|---|---|---|
| population grid | `data/population/persona_grid_v3.json` | L1 | calibrated from public survey microdata | derived table; code MIT, data CC-BY-4.0 | yes (repo) | TODO |

| NAV cache | `data/funds/nav_cache.json` | L1 (fetched) | public NAV APIs | public data; refresh it yourself | NOT uploaded -- run `script/fetch_data.sh` | computed locally |
| creative images | `data/**/images/` | L0 | platform | never redistributed | never | n/a |

Rules of thumb: L0 inputs never leave the machine that collected them; every
emitted L1/L2 file gets a row in `data/MANIFEST.sha256`
(`sha256  size  path`); images are referenced but never copied.
