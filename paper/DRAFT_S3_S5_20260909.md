## §3 方法论骨架：六环链与三层验证

### 3.1 我们要解释什么

我们要解释的不是"某一条营销内容有没有效"，而是**一个平台上的微观互动如何长成宏观结构**：几万次点赞、评论、点击、申购的个体决策，如何在十几个交易日里凝结成"极少数内容吃掉几乎全部转化"的注意力格局，以及机构与监管规则如何调制这个过程。

这决定了方法论的选择。要回答"如何长成"，需要的不是一个拟合宏观矩的模型，而是一个**生成式解释**（Epstein 1999）：把个体放进环境里自己跑，看宏观量是否从下往上出现。因此我们采用 LLM 驱动的生成式 agent 社会模拟，并把整个系统拆成一条闭合的六环链。

### 3.2 六环链

复杂适应系统的最小闭环是六个环节（Holland 1995；Miller & Page 2007）。我们的实现逐环对应如下，每一环都给出**引擎里的对应物**与**可观测量**：

| 环 | 引擎实现 | 事件日志里的可观测量 |
|---|---|---|
| **Agent**（个体） | LLM 散户：人口分层抽样、风险测评等级 C1–C5、现金与开局持仓、六维信念、5 日滚动记忆、每 5 日一次反思 | `dec`（决策、心情、理由）、`refl`（反思） |
| **Interaction**（互动） | 信息流卡片携带社会证明信号（t−1 的点赞数）、评论区舆论标签、三条热评；大 V 层开启时热评带作者句柄与粉丝数，个体可关注个体 | `imp`、`cmt`、`clim`、`st`（含 `follow_user`） |
| **Environment**（环境） | 三源信息流排序、200 条真实营销笔记（含图片与 OCR）、真实基金净值（外生）、股吧注意力信号、适当性匹配检查 | `post`、`click`、`co`（结账结果） |
| **Feedback**（反馈） | 昨日互动 → 今日热度与舆论标签 → 影响今日排序与决策，严格滞后一日 | 卡片上的 `likes` 与 `climate_label` |
| **Adaptation**（适应） | 个体：反思改写两维信念、对机构累积熟悉度与好感度；机构：每 5 个交易日按上一周期各意图帖收到的响应重配意图权重 | `refl`、`inst` |
| **Collective Outcome**（集体结果） | 曝光与转化的集中度、羊群指标、立场熵、评论爆发、机构意图漂移、粉丝分布与关注图同质性 | 分析层七个模块的 JSON |

**闭合性检验**：每一环都必须既受上游影响、又影响下游，否则该环是装饰。我们对每个开关都做了"关闭时事件日志逐字节相同"的验证（`docs/RUNBOOK.md` §15），这既保证了开关的正确性，也证明了开启时的差异确实来自该机制而非实现噪声。

### 3.3 三层验证

沿用 TwinMarket（NeurIPS 2025）的验证哲学，但把三层的内容换成我们这个场景该有的东西：

1. **微观真实（§4）**：单个 agent 的决策是否像一个真实的中国基民？可靠性（能否稳定产出可解析、可重放的决策）、处理效应（同样的内容换一种模态，行为是否按预期方向变化）、以及**边界**（哪些真实行为它做不出来）。
2. **宏观真实（§5）**：把所有个体加起来，平台层面的统计规律是否与真实社交平台的定型化事实一致？集中度、情绪分布、评论爆发的重尾。
3. **涌现（§6）**：宏观结构是否是从微观互动中**长出来**的，而不是被参数设定的？判据是：机制开关一关，结构消失；开关一开，结构在没有被直接编码的情况下出现。

### 3.4 与最接近的工作的区别

TwinMarket 用 BDI 架构的 LLM agent 复现了股票市场的肥尾、波动聚集与自我实现预言。我们与它共享"LLM agent 产生宏观金融规律"的问题意识，但三处不同决定了我们不是它的复制：

- **产品不是股票而是公募基金**：个体买的是份额，不是撮合成交的标的；
- **机制不是订单簿而是营销与适当性**：驱动力来自内容排序、社会证明与合规规则，不是价格竞价；
- **散户资金不驱动价格**：净值是外生的真实序列，因此我们**没有**"价格→行为→价格"的自我实现回路，取而代之的是"可见度→行为→可见度"的注意力回路。这条回路才是本文的"价格"。

这个替换是有意的：它让我们能用真实净值做外生冲击，同时把因果注意力集中在平台机制上。

## §4 微观真实

本节的全部数字来自一次 100 人 × 12 交易日的真模型运行（`runs/out/live_pilot_100x12`，glm-4.6v，三组模态 agent 级随机化，真实净值与真实图片）。主网格 400 人 × 5 种子的结果见【待填：main_ref_s2027..6071】。

### 4.1 决策可靠性

生成式 agent 研究的第一个可信度门槛是：模型能不能在成千上万次调用里稳定输出可解析、可复现的决策。我们的测量：

| 指标 | 值 | 来源 |
|---|---|---|
| 模型调用总数 | 1,400（1,200 次决策 + 200 次反思） | `run_meta.counters` |
| 终态失败 | 0 | `decision_failures` |
| 传输侧失败 / 模型侧失败 | 0 / 0 | 同上 |
| 图片附着 | 2,376 张，缺失 0，摘要不匹配 0 | `run_meta.images` |
| 一致性检查 | 13 项，0 失败（3 项因单臂/无赎回而不适用） | `invariants_report.json` |
| 缓存重放 | 逐字节相同 | `--replay-check identical=True` |

需要说明的是首次尝试的失败率并不低：约 15% 的调用第一次返回不合 schema 的 JSON，全部在重试梯内救回，最多一次用了 5 轮。这说明**推理型模型的输出畸形率是这类研究真实的工程风险**，我们把它记录为传输层与模型层分离的两个计数器，并把停机阈值的样本下限定为 100 次调用——在 40 次调用上算失败率会把一次偶发失败误判成 2.5% 的系统性故障（预注册 D24）。

### 4.2 模态处理效应（主终点）

**设计**：同一个世界内，每个 agent 被随机分入三组之一，同一条笔记以三种形态呈现：纯文本组（T，只有标题与正文）、文字描述组（TC，加图内 OCR 文字与一句冻结的画面描述）、真图组（TV，直接附上图片像素）。TC 的存在让我们能把"图片的效果"分解成两半：TC−T 是**图里的信息**带来的增量，TV−TC 是**像素本身**带来的增量。

**冻结描述的定义**（预注册 D22）：glm-5.3-flash 对 801 张图各生成一句 ≤30 字的中文描述，提示明确禁止抄写图内文字（OCR 已单独提供）、只写版式与视觉元素。第一版提示曾要求 ≤40 字且未禁止抄写，结果 550/800 条在 40 字处被硬截断、425 条在重抄图内文字，已废弃。定稿版触到上限的仅 6/800，抄写为 0。代价是 57 条（7%）带出了颜色词，我们披露该偏差并预注册一条稳健性检查：剔除这 57 张图所属笔记后重算 TV−TC。

**试跑上的方向性结果**（n=1 次运行，仅作描述，不做推断）：

| 组 | 人数 | 决策数 | 点击率 | 申购转化率 |
|---|---|---|---|---|
| 纯文本 T | 33 | 396 | 0.396 | 0.391 |
| 文字描述 TC | 34 | 408 | 0.429 | 0.419 |
| 真图 TV | 33 | 396 | 0.437 | 0.434 |

三组在点击率与转化率上都呈 T < TC < TV 的单调序，与预注册的方向假设一致；但单次运行没有推断力，主终点以 5 个种子的种子级 t 区间为准【待填】。

### 4.3 一个明确的边界：12 日内从不卖出

**观察**：1,200 次决策里，模型自报的交易动作只有 `none` 829 次与 `buy` 670 次，`redeem` **0 次**。

这不是机制不通，证据有四条：

1. 决策解析零违规，没有任何被引擎拒绝的赎回；
2. 同一引擎在规则型基线上产生 26 笔赎回，处置效应 DE = +0.056（PGR 0.293 / PLR 0.237），阳性对照通过；
3. 环境里有亏可卖：窗口内有净值的 390 只基金里 293 只下跌（中位 −2.33%），运行期买入的 498 笔到末日有 134 笔（27%）浮亏；
4. 亏损是可见的：后三日的 300 次决策里有 158 次由手上持有浮亏仓位的 agent 做出，无一卖出，理由高度同质——"坚持定投""长期看好""心态平稳"。

**含义**：这一代 LLM 散户在 12 日窗口内表现为**极端的买入持有**。它在方向上与处置效应（不愿卖亏损）一致，但在程度上超出了真实投资者——真实中国基民会赎回，否则 2017 年也不会有针对短期赎回的惩罚性费率规定。按 Wu & Peng（2025）的边界论，这是集体层定性结论必须披露的一条限制。

**后果**（已写入预注册 D25/D26）：处置效应的模态假设在 12 日主网格上不可估，改为零结果报告；七日惩罚费规则的暴露面恒为 0，其行为披露臂撤下；处置效应只在规则型基线与 40 日涌现运行上给出。

顺带澄清一个容易被误解的技术点：开局浮亏比例的上限不是配置错误，而是真实净值史的限制。即便按目标模式要求 50% 的开局持仓浮亏，实际只能做到 6.6%（578 笔里 38 笔），因为要在窗口起点构造一笔浮亏，必须在该基金历史上找到一个净值更高的买入日，而这批基金在样本期大多上涨。

### 4.4 内容侧的合规暴露

我们把 2020 年《公开募集证券投资基金宣传推介材料管理暂行规定》与 2026 年《金融产品网络营销管理办法》的可编码条款整理成七条规则（R01–R07），用词表加模型两遍对 200 条真实笔记打标（glm-4.6，108 次模型裁定，零失败）：

| 规则 | 命中笔记数 |
|---|---|
| R07 未经核实的数据 | 31 |
| R01 保本或承诺收益 | 15 |
| R06 诱导性用语 | 10 |
| R03 无依据的极端表述 | 7 |
| R04 业绩展示无区间或无提示 | 4 |
| R05 推品帖缺少风险提示 | 3 |
| R02 预测未来业绩 | 0 |

64/200 条笔记命中至少一条规则；推品帖（I2）的命中率 40%，非推品 27.7%。R02 零命中值得单独说明：词表挑出 4 条候选全部被模型否掉，我们在人工抽检的 30 条样本中重点复核该项。结论只作描述性，不作因果断言（预注册 D28）。

## §5 宏观真实

### 5.1 曝光是广的，转化是赢者通吃的

这是本文最清晰的一条宏观规律。同一批 96 条帖子，在漏斗的三个环节上集中度差异极大：

| 环节 | 有非零值的帖子数 | Gini | 头部单帖份额 | 前五帖份额 |
|---|---|---|---|---|
| 曝光（7,200 次） | 92 / 96 | 0.592 | 3.9% | 17.9% |
| 点击（505 次） | **5 / 96** | 0.972 | 41.4% | 100% |
| 申购（498 笔） | **5 / 96** | — | 41.8% | 100% |

排序算法把曝光相对均匀地铺开（Gini 0.59，头部帖只占 3.9%），但**转化几乎全部落在 5 条帖子上**，其中一条独占四成。也就是说，注意力的坍缩不发生在分发环节，而发生在**从看到到点击**这一步——个体在几乎相同的曝光机会下，把点击集中投给了极少数内容。

这与真实平台的定型化事实一致，也和 Ben-David 等（2022）的观察相呼应：基金投资者依赖极简信号，因而对内容的选择高度集中。

### 5.2 情绪单极化

1,082 条评论的立场分布：看多 841、观望 241、**看空 0**。立场熵 0.765 bit（在两标签上归一后仍为 0.765）。按日看，第 0 日观望多于看多（熵 0.905），随后迅速倒向看多。

一个没有看空声音的舆论场是本模型的显著特征，也是一条需要披露的边界：真实评论区存在唱空。这与 §4.3 的零卖出是同一个倾向的两个侧面——这一代 agent 的默认人格偏乐观、偏持有。

### 5.3 评论爆发的重尾

单帖评论数排序后为 218、156、137、97、95、75、…，Gini 0.893，96 条帖子里只有 40 条收到过评论。评论的集中度介于曝光与点击之间，说明"愿意留言"是一个比"愿意点击"更宽、比"被看到"更窄的筛子。

### 5.4 一个失效的指标，以及为什么照实报告

我们预注册了 LSV 羊群指标作为全市场层面的基准。本次运行上它**没有定义**：所有格子里只有买方，买入比例恒等于 1，指标无信息量。这是零卖出（§4.3）的直接后果，不是实现错误。我们照实报告并保留该指标用于规则型基线与 40 日涌现运行。

### 5.5 机构层的意图漂移

即使在机构适应关闭的运行里（意图混合由数据外生给定），平台层面的推品帖占比仍随时间上升：0.375 → 0.425 → 0.438，意图组合熵从 1.579 降到 1.505。这条基线很重要——它说明**在没有任何机构学习机制的情况下也存在漂移**，因此涌现运行里若观察到更快的漂移，必须与这条基线相减才能归因给适应机制。

## §6 涌现（骨架，等运行结果）

判据（预注册 D31–D33）：一个结构算作"涌现"，必须同时满足两条——(a) 它没有被任何参数直接设定；(b) 关掉产生它的微观机制，它消失。

三条待验证的涌现链：

1. **注意力级联**：种子热度实验（Muchnik–Aral–Taylor 2013 设计）在帖子发布时随机把首日显示的点赞数抬高 k=10，排序与真实计数不受影响，两组曝光完全相同。主因变量是级联乘数：到 t+2 累计多出的互动除以 k。乘数大于 1 且逐日增长意味着正反馈存在；衰减意味着系统自我修正。k 的定标依据来自试跑：每帖首日曝光中位 5 次、首日点赞中位 0（均值 2.6），k=10 相当于让一条新帖看起来像已经小火的帖子，正是"买赞"的操作化。【待填：heat_seed_s2027/3031/4049】
2. **意见领袖与回音室**：大 V 层开启后，热评按作者粉丝数排序，形成"粉丝多→被展示→粉丝更多"的优先连接回路。终点是粉丝分布的集中度、关注图的立场同质性（与保出度重连零模型比较）、跟单率，以及影响与同质性的粗分解（Aral 等 2009）。【待填：emerge_s*】
3. **机构规范收敛**：机构按响应重配意图权重后，四家的权重是收敛还是分化（两两 L1 距离），以及适当性检查开关是否改变滑向推品的速度。基线见 §5.5。【待填：emerge_s*】
