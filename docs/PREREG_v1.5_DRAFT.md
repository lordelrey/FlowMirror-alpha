## A. 多模态：从附录消融升为第二条主线（取代 v1.1 §C 首行、v1.3 §B10 的两臂设定）

### A1. 三档模态臂
| 臂 | Feed 卡片中的图片部分 |
|---|---|
| **T** | 「配图不展示」，无任何图片信息 |
| **TC** | 不给像素；给 OCR 原文 + 一句 ≤40 字**中性内容描述**（离线由 glm-4.6v 按冻结提示生成，写入内容池字段 `image_caption_frozen`；提示禁止评价词与颜色/表情等视觉专属词；业主人工抽检 30 张，保真度 ≥8/10 方可使用） |
| **TV** | 真实图片像素（≤768 px，每卡 ≤1 张，每日每人 ≤3 张） |
分解：TC − T = 图片携带的**信息**效应；TV − TC = **视觉呈现**效应。

### A2. 随机化单位
- **agent 级**（主网格内）：每个 agent 整场固定一臂，`arm = rng_for(run_tag, "arm", agent_id)` 按 1/3 等概率；不变量 (h) 改为（决策 16，与 `feed.check_arm_balance` 的实现逐条对齐）：整体上每臂
  份额 |·−1/k| ≤ **0.01**；格内容差为 **max(1/(2·n_cell), max(m, k−m)/(k·n_cell))**，其中
  n_cell 是该格人数、k 是臂数、m = n_cell mod k。旧文本写的 0.03 / 0.05 有两处问题：格内
  0.05 对 n_cell=2 数学上不可满足（这是决策 12），而整体 0.03 比代码实际执行的 0.01 宽三倍。
  五个预注册种子上实测偏差为 0.0000，所以 0.01 完全可满足，且它才是运行时真正的判据。
- **整场级**（参考格 {suitability on, measured, three_source}）：全 T / 全 TC / 全 TV 各 **2 种子**，共 6 次运行，用于社会级效应。
- 曝光级臂保留为敏感性选项，不进报告。

### A3. 终点（预注册）
| 层 | 主/次 | 量 | 检验 |
|---|---|---|---|
| 微观 | **主 1** | 互动率 P(like 或 save \| 曝光) | agent 级两两对比（TV−TC、TC−T、TV−T），比例差 Cohen's h，种子级 t 区间（df=4） |
| 微观 | **主 2** | 评论率 P(comment \| 曝光) | 同上 |
| 微观 | **主 3** | 机构好感增量均值 `org_affinity_delta` | agent 级均值差，Cohen's d，种子级 t 区间 |
| 微观 | 次 | 点击率 P(click \| I2 曝光)、申购转化 P(subscribe \| click) | 同上 |
| 中观 | 次 | 帖子热度基尼系数、气候标签分布、机构到 level 1/2 的中位天数 | 整场级臂间对比 |
| 宏观 | 探索 | 族级资金流 Herfindahl、LSV、Δ1 与 r_off−r_on 在各臂下的差 | 整场级；只报点估计与区间 |
- **SESOI**：h = 0.10（≈5 个百分点）；d = 0.20。三分判定沿用 v1.2 §E（区间下界 > 0 / 上界 < SESOI / 不定）。
- **预期方向（据 Li–Xie 2020、Pieters–Wedel 2004、MacKenzie–Lutz–Belch 1986）**：主 1–3 上 TV > TC > T，其中 TV−TC 中等、TC−T 小；**次终点（交易）预期无可辨识差异**——若成立，措辞为「在本模型下，图片呈现改变互动与好感，不改变结构化交易决策」，这是预注册的发现之一，不是失败。
- **审计**：感知保真（TV 臂独立调用描述所见图，与 OCR/人工标签比对命中率 ≥0.8）；模态泄露（TC 描述词表抽检，视觉专属词零命中）；反诱导（提示不含"图片/配图效应/实验"）。

## B. 投资者层量化（把 DECISIONS #1–#5 写死）
- 信念：2 维 agent 可写（market_view、risk_mood，1–5，反思时改写）+ 6 维引擎数值；反思每 5 交易日，记忆 5 日文字日志。
- 立场四类 {bullish, bearish, watching, no_comment}；气候聚合只用前三类。
- 一日一笔，百分比金额，最低 100 元。
- 熟悉度 δ=0.2、level 阈值 1.0；trust λ_a=0.9；attention λ=0.8 记法 `att_t=λ·att_{t−1}+曝光+β·z_guba`；**敏感性臂**：阈值 0.5 与 2.0 各 1 种子（参考格）。

## C. 平台层（DECISIONS #6、#13）
- 热度 h=log10(赞+2收藏+3评论+1)/(age+1)^1.8；气候 min_n=4、margin=1/6；展示"共 n 条评论"+ 多数标签 + 前 3 热评。
- **校验义务**：运行前用内容池真实笔记的 赞:收藏:评论 中位比检查权重 1/2/3 的合理性；若中位比与 1/2/3 的相对关系相反，改为稀缺度倒数并在此记录（运行前）。
- 阈值敏感性：min_n ∈ {3,6}、margin ∈ {1/10, 1/4} 各 1 种子（预算允许时）。

## D. 市场层（DECISIONS #12）
- 费率：申购 0.12%、赎回 0.5%（可配置）；成交仍当日；财富守恒式 = 现金 + 持仓市值 + 实现盈亏 + **累计费用** = 初始（容差不变）。

## E. 通道范围（DECISIONS #9）
- 主网格通道：feed、experience、social、news 开；**trend、direct 关**。trend 作 1 次消融（2 种子，参考格）。

## F. 基线族（DECISIONS #11）
- 规则型空模拟器 = 两条文献规则（处置效应两档赎回概率；追涨申购概率 ∝ 近 3 月收益分位）+ 人口均值率互动 + 其余均匀；参数取自参考格首个种子的人口平均响应率，**在见到主网格结果前固定**。
- 基线族：空模拟器、无状态 LLM（memory=false）、随机排序 LLM。

## G. 8 机构因子二（DECISIONS #14；数据到位后填分组）
- 规则：按打标后各机构实测 I2 占比排序，前一半 = 推品重，后一半 = 投教重；奇数家时中位一家剔出因子二（仍在场，用 measured）。分组在打标后、任何生产运行前写入 `strategy_groups` 并记录 sha。
